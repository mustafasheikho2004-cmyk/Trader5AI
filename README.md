# Trader 5 AI

Android trading app concept with AI signals, crypto/forex tracking, and dark premium UI.

## Features
- AI buy/sell/wait signals
- Live-like market cards
- Forex and crypto watchlist
- Technical indicator visualization concepts
- Dark trading dashboard

## To run in Android Studio
1. Open Android Studio.
2. Choose `Open` and select this folder.
3. Let Gradle sync.
4. Run the app on an emulator or connected device.
5. Build APK from `Build > Build Bundle(s) / APK(s) > Build APK(s)`.

## Notes
This is a UI prototype and mock trading dashboard designed as a foundation for a full production app.
